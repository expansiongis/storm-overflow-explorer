ExpansionGIS Storm Overflow Explorer — upload package

This package combines the Dynamic Dashboard v2 HTML with the exact EXP + globe wordmark you selected and matching favicon assets.

PUBLISH TO GITHUB PAGES
1. Open https://github.com/ExpansionGIS/storm-overflow-explorer
2. Back up your current index.html (or make a commit first).
3. Upload/replace index.html from this package in the repository root.
4. Upload the five image/icon files in this package into the same root folder.
5. IMPORTANT: keep your existing config.js in the repository root; this package intentionally does not include or replace it.
6. Commit the changes. GitHub Pages should redeploy automatically.
7. Open https://expansiongis.github.io/storm-overflow-explorer/ and hard refresh with Ctrl+F5 if the old favicon is cached.

WHAT'S INCLUDED
- Dynamic Dashboard v2: Overview, Water companies, Rainfall & rivers, History & trends panels; multi-company map and existing filters/customize flow retained.
- EXP-wordmark.png: exact selected EXP + globe design.
- favicon.png, favicon-32.png, favicon.ico, apple-touch-icon.png: browser and bookmark icons.

NOTE
The Rainfall & rivers and History & trends panels are currently marked as next-build placeholders in this v2 HTML; they are not live data integrations yet.


DASHBOARD BUTTON UPDATE
The map dashboard starts collapsed. Click “EXPLORE THE DATA” in the map header to open the dashboard table and tabs; click again to collapse it.
